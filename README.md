# REST Assured with Java: Interview Study Guide

By Shreya Gopal. Open it through a web server, for example `python3 -m http.server` in this folder, then
visit http://localhost:8000.

| Concern                         | Where                                                                        |
|---------------------------------|------------------------------------------------------------------------------|
| Page structure                  | `index.html`                                                                 |
| Lesson text (one file per part) | `content/`                                                                   |
| Look and feel                   | `css/` (tokens, base, layout, content, code, labs, quiz, extras, responsive) |
| Behaviour                       | `js/` (utils, highlight, layout, quiz, study, main)                          |
| Demo code (one file per demo)   | `js/labs/`                                                                   |
| Questions, answers and tasks    | `data/`                                                                      |

To add a question, edit a file in `data/`. To add a lesson, edit a file in `content/`. To change colours, edit
`css/tokens.css`.
